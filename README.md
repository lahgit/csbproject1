# csbproject1
cybersecurity mooc course

project was implemented with Django.
Project doesn't have example accounts that can be seen in screenshots by default.
Creating accounts can be done in the registration link on the index page or you can create a Django superuser manually.

clone this repository with git clone

To start go to mysite folder then run

python3 manage.py makemigrations

python3 manage.py migrate

python3 manage.py runserver
